# 센서값 매핑 블록 — 총 13종

AI로봇집게 [왼쪽 조도 ▼] 센서값을 입력 (0) ~ (1023)에서 출력 (0) ~ (180)으로 변환

이 블록은 숫자를 반환하는 값 블록입니다. 변환 결과를 관절 각도, LED 밝기, 부저 주파수, 비교식 등의 숫자 입력 칸에 넣습니다. 블록 자체가 로봇을 움직이지는 않습니다.

- 센서 선택: 왼쪽 조도, 오른쪽 조도, 상하/좌우/집게 가변저항.
- 입력 시작/끝과 출력 시작/끝은 숫자, 변수, 계산식으로 지정 가능합니다.
- 기본값: 센서 0~1023 → 각도 0~180.
- 입력 범위를 벗어나면 해당 끝값으로 제한합니다. 예: 입력 200~800 → 출력 0~180에서 센서가 100이면 0, 900이면 180.
- 반대 방향: 입력 0~1023 → 출력 180~0.
- 입력 범위의 시작과 끝이 같으면 오류를 표시합니다. NaN/Infinity 등 유효하지 않은 범위도 거부합니다.
- 변환 결과는 소수점을 유지합니다. 최종 관절/LED 명령은 기존 방식대로 반올림 및 범위 제한합니다.
- 입력 시작이 끝보다 큰 역방향 입력 범위도 지원합니다. 출력 시작과 끝이 같으면 일정한 값이 나옵니다.

## 사용 예

| 목적                      | 입력   | 출력   | 넣을 자리     |
| ------------------------- | ------ | ------ | ------------- |
| 가변저항으로 관절 제어    | 0~1023 | 0~180  | 관절 각도     |
| 조도에 따라 LED 밝기 변경 | 0~1023 | 0~255  | 파란 LED 밝기 |
| 어두워질수록 LED를 밝게   | 0~1023 | 255~0  | 파란 LED 밝기 |
| 관절 이동 구간 제한       | 0~1023 | 60~120 | 관절 각도     |

연속 제어는 기본 반복문 안에 '관절 각도 설정(매핑 블록)'과 '0.05초 기다리기' 등을 넣습니다. 센서 블록을 한 번만 실행하면 그 시점의 값만 적용됩니다.

## IFRAME 시험

수정본 개발 서버를 실행하고 연결한 뒤 센서 매핑부터 확인할 수 있습니다.

```js
logger.log(await hw.mapSensor(3, 0, 1023, 0, 180));
logger.log(await hw.mapSensor(3, 0, 1023, 180, 0));
```

각도 매핑 제어 예시는 아래와 같습니다. 세 관절 중 상하의 목표각만 변경합니다.

```js
await hw.start();
await hw.servo(1, await hw.mapSensor(0, 0, 1023, 60, 120));
```

센서 원시값은 기존대로 8비트 수신 후 0~1023으로 환산한 값입니다. 매핑으로 센서의 실제 측정 해상도가 높아지지는 않습니다.
펌웨어·USB 연결 처리·전송 패킷은 변경하지 않았습니다. mapSensor() API 및 블록 정의/제너레이터/미리보기를 추가했습니다.
