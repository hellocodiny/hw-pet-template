# AI로봇집게+ · AI코디니 USB BLE 동글 연동

1단계에서 확인한 USB 동글 연결/검색/선택/초기화/센서 수신에 제어 기능을 추가했습니다.
펌웨어는 수정하지 않았습니다. PC 프로그램의 통신 규격과 관절/LED 매핑을 적용했습니다.
2단계에서 사용자가 실물 제어 정상 동작을 확인했습니다. 블록19종의 정의/제너레이터/목록과 지원 API를 추가했습니다. 코디니 서비스에 자동 등록되는 패키지는 아닙니다. 로컬 Blockly 편집기는 포함하지 않습니다.

먼저 BLOCK_LIST_KO.md에서 블록 구성을 확인하고 IFRAME_TEST_KO.md로 새 API를 시험합니다. 실제 등록은 REGISTRATION_KO.md를 참고하세요.

## 실행

기존 서버를 터미널에서 Ctrl+C로 종료하고, 새 폴더에 압축을 푼 뒤 `aiRobotGripperPlus-serial` 폴더를 VS Code로 엽니다.

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd test
pnpm.cmd dev
```

Chrome에서 http://localhost:3000 에 접속합니다. 터미널에 다른 포트가 표시되면 해당 주소를 사용합니다.
PC 제어 프로그램/엔트리 하드웨어/시리얼 모니터는 종료합니다.

## 먼저 로봇 한 대 시험

1. 로봇 전원을 켜고 USB BLE 동글을 연결합니다.
2. USB 동글 연결 → 동글 포트 선택 → 검색 완료 → 이 로봇 연결.
3. 초기화 확인됨, code=2, 센서값 변화 확인.
4. 관절 기본 명령값은 90°입니다. 첫 일반 제어 명령(LED/부저/기본 이동 포함)이 세 관절을 이 값으로 움직일 수 있습니다.
5. 관절 방향 버튼/각도 적용 → 네오픽셀 색/모두 끄기 → 부저 → 짧은 시간 이동 순서로 확인합니다.
6. 계속 이동과 전체 출력 정지를 확인합니다.

## 로봇 추가·제외

- 함께 사용할 로봇을 모두 켠 상태에서 최초 검색합니다. 같은 그룹 1, 서로 다른 번호(1~20)를 사용합니다.
- 한 대를 직접 연결합니다. 해당 로봇은 필수 제어 대상이며 센서값의 출처입니다.
- 나머지 검색된 로봇에서 `함께 제어`를 체크하면 대상에 추가됩니다. 체크 해제하면 제외됩니다.
- 변경할 때 기존 대상의 바퀴/부저/LED 출력 정지 후, MODE=0 초기화 응답을 확인합니다. 이전 시간 지정 명령은 취소합니다.
- 변경 완료 후 새 제어 버튼을 눌러 동작시킵니다. 정지된 동작을 자동으로 재개하지 않습니다.
- 체크 표시는 송신 대상 선택입니다. 추가 로봇의 접속/수신/실행 완료를 개별 확인한 표시가 아닙니다.
- 동글은 직접 연결한 한 대에 BLE 연결하고, 그 로봇이 나머지 대상에 명령을 중계합니다.
- 나중에 전원을 켜서 목록에 없는 로봇은 연결 해제 → 다시 연결/검색해야 합니다. 연결 중 새 검색은 동글에서 지원하지 않습니다.
- 추가 로봇의 센서값은 수신하지 않습니다. 배터리는 검색 당시 정보이며 실시간 값이 아닙니다.

## 제어 기능

| 기능           | 동작                                                                        |
| -------------- | --------------------------------------------------------------------------- |
| 이동           | 전진/후진/좌회전/우회전, 지정 시간 또는 계속 이동                           |
| 속도           | 전진/좌회전/우회전 0~255, 후진은 펌웨어 고정 속도                           |
| 관절           | 상하 위0/중간90/아래180, 좌우 왼180/중간90/오른0, 집게 열0/중간90/닫180     |
| 네오픽셀       | 전체, 왼쪽 묶음(1·3), 오른쪽 묶음(2·4), 개별1~4, 모두 끄기                  |
| 색상           | PC와 동일하게 선택 색상의 최대 RGB 성분을 100으로 환산                      |
| 부저           | 옥타브2~6, 도레미파솔라시, 시간 지정; 최대2040Hz/8Hz 단위                   |
| 바퀴 정지      | 바퀴만 정지. LED/부저 상태 유지                                             |
| 전체 출력 정지 | 예약 명령 취소, LED/부저/바퀴 정지 명령, MODE=0. 다음 버튼으로 새 제어 가능 |

배터리 경고 LED/소리는 로봇 펌웨어가 우선 제어하므로 일반 출력 정지로 해제되지 않을 수 있습니다.
탭이 숨겨지면 활성 출력을 정지합니다. 창 닫기/USB 탈착 시 즉시 무선 전달을 보장할 수 없으며, 기존 펌웨어 통신 시간 초과 정지에도 의존합니다.

## 기술 및 제한

- 115200bps, FE EF 20바이트 중계 프레임, CRC8(poly07), 그룹1, 1~20번 대상 마스크.
- MODE=0 초기화는 FE EC code2의 로봇 번호/시퀀스/CRC 및 USB 쓰기 완료를 확인합니다.
- ACK는 직접 연결된 모듈의 초기화 수락입니다. 원격 전체 로봇의 실행 ACK가 아닙니다.
- 일반 제어 명령은 한 대일 때 최소32ms, 여러 대일 때 최소110ms 간격으로 전송합니다. 긴 이동/연주는 주기적으로 상태를 갱신합니다.
- PWM 동작 중 일반 출력 패킷은 MOTOR=0xFF로 PWM을 보존합니다.
- 시간 지정은 USB 쓰기 완료를 기준으로 하며, 무선 및 모듈 처리 지연 때문에 실물 동작 시간이 정확히 같다고 보장하지 않습니다.
- 모듈 보호 정지(code1/3), 연결 오류 시 명령 전송을 중단합니다. 연결 해제 후 다시 연결하세요.
- 직접 연결된 로봇의 센서 수신이 2초 넘게 멈추면 값을 숨기고 출력 정지를 시도합니다.
- 실제 KT 서비스 ID/배포 경로/블록 라우팅 접두어, 프로그램 전체 정지 이벤트 연결은 아직 KT 확인 및 후속 개발이 필요합니다.
- 블록 등록 전 IFRAME Playground에서 새 API를 시험한 뒤, 코디니 등록 및 실행을 확인합니다.
