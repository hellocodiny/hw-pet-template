- 센서 모니터는 코디니 무대가 아닌 하드웨어 교구창에 표시합니다.
- 센서 및 매핑은 직접 연결된 로봇 기준입니다. 출력은 화면에서 선택한 모든 대상에 적용합니다.
- PC의 초음파 전용 매핑을 센서 선택형으로 확장했습니다. 입력 범위가 같으면 오류, 결과는 소수점 유지입니다(PC는 결과 반올림). 각도/LED 번호 등의 최종 출력 함수에서 필요 시 반올림합니다.
- 실제 미장착 가운데 적외선은 제외했습니다.
- 반복/조건/변수/함수는 코디니 기본 기능을 사용합니다.
- 교구창에서 함께 제어할 로봇을 선택합니다. 별도 대상 변경 블록은 추가하지 않았습니다.
- 제어 재개/출력 정지 블록은 없습니다. 바퀴 정지와 LED 모두 끄기는 포함합니다.
